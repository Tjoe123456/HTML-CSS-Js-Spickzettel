Wie HTML grundsätzlich funktioniert

HTML besteht aus Elementen. Ein Element sagt dem Browser: „Dieser Teil der Datei ist eine Überschrift / ein Absatz / ein Link / ein Bild / eine Liste usw.“

Ein sehr einfaches Beispiel:

<p>Hallo Welt!</p>

Das bedeutet:

<p> öffnendes Tag
Hallo Welt! Inhalt
</p> schließendes Tag

Zusammen ergibt das ein Element:

<p>Hallo Welt!</p>
Element

Grundgerüst einer HTML-Datei

Jede HTML-Datei beginnt grundsätzlich mit diesem Aufbau: 

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Meine Website</title>
</head>

<body>

</body>
</html>

Bedeutung der einzelnen Teile

<!DOCTYPE html> sagt dem Browser, dass es sich um ein modernes HTML5-Dokument handelt.

<html> enthält die komplette Website.

<head> enthält Informationen über die Website, die normalerweise nicht direkt auf der Seite angezeigt werden.

<meta charset="UTF-8"> sorgt dafür, dass Umlaute wie ä, ö, ü und Sonderzeichen korrekt dargestellt werden.

<title> — der Text erscheint oben im Browser-Tab.

<body> — hier kommt alles hinein, was auf der Website sichtbar sein soll.

Sprache der Website

Das <html>-Element sollte die Sprache der Seite angeben, für eine deutsche Website: 

<html lang="de">

Für Englisch entsprechend <html lang="en">.

Überschriften

HTML hat sechs Überschriftenebenen: 

<h1>Größte Überschrift</h1>

<h2>Zweite Ebene</h2>

<h3>Dritte Ebene</h3>

<h4>Vierte Ebene</h4>

<h5>Fünfte Ebene</h5>

<h6>Kleinste Überschrift</h6>

h1 ist normalerweise die wichtigste Hauptüberschrift der Seite. Die Reihenfolge sollte logisch sein — nicht einfach eine h5 verwenden, wenn eigentlich eine Unterüberschrift von h1 gemeint ist (also h2).

Richtiges Beispiel:

<h1>Mein Bergprojekt</h1>

<h2>Meine Touren</h2>

<h3>Alpen</h3>

Text, Zeilenumbruch & Hervorhebung

Normaler Text

Für normalen Text benutzt man <p>. Ein Absatz sollte normalerweise einen zusammenhängenden Textblock enthalten. 

<p>Das ist der erste Absatz.</p>

<p>Das ist der zweite Absatz.</p>

Zeilenumbruch

Wenn innerhalb eines Textes ein Zeilenumbruch gewünscht ist, wird <br> verwendet. Es braucht kein schließendes </br>. 

<p>
    Montag<br>
    Dienstag<br>
    Mittwoch
</p>

Text hervorheben

Für wichtigen Text: <strong>Wichtiger Text</strong>. Für Betonung: <em>Betonter Text</em>.

Für einfache Webseiten können auch <b> (fett) und <i> (kursiv) verwendet werden — semantisch sinnvoller sind aber meistens strong und em.

Links

Ein Link wird mit <a> erstellt, href bestimmt das Ziel: 

<a href="https://example.com">Diese Website öffnen</a>

Link zu einer anderen HTML-Seite

Wenn im selben Ordner beispielsweise diese Dateien liegen: 

index.html
touren.html
ausruestung.html
kontakt.html

dann kann man verlinken:

<a href="touren.html">Touren</a>

<a href="ausruestung.html">Ausrüstung</a>

<a href="kontakt.html">Kontakt</a>

Datei in einem Unterordner

Wenn die Struktur so aussieht:

index.html
touren/
    touren.html

dann:

<a href="touren/touren.html">Touren</a>

Eine Ebene zurück

Wenn man sich beispielsweise in touren/tour.html befindet und zurück zu index.html möchte: 

<a href="../index.html">Startseite</a>

.. bedeutet: eine Verzeichnisebene nach oben.

E-Mail-Link

<a href="mailto:beispiel@example.com">
    E-Mail schreiben
</a>

Beim Anklicken wird das entsprechende E-Mail-Programm geöffnet.

Telefonnummer

<a href="tel:+491234567890">
    +49 123 4567890
</a>

Auf unterstützten Geräten kann dadurch direkt angerufen werden.

Externe Links

Wenn der Link in einem neuen Tab geöffnet werden soll, sollte aus Sicherheitsgründen zusätzlich rel="noopener noreferrer" verwendet werden: 

<a
    href="https://www.example.com"
    target="_blank"
    rel="noopener noreferrer"
>
    Externe Website öffnen
</a>

Das nav-Element

Eine einfache Navigation kann so aussehen:

<nav>
    <a href="index.html">Startseite</a>
    <a href="touren.html">Touren</a>
    <a href="ausruestung.html">Ausrüstung</a>
    <a href="ueber-mich.html">Über mich</a>
</nav>

<nav> sagt dem Browser: dieser Bereich enthält Navigationslinks.

Bilder

Ein Bild wird mit <img> eingefügt:

<img src="bild.jpg" alt="Beschreibung des Bildes">

src gibt an, wo das Bild liegt. alt beschreibt das Bild. 

<img src="berg.jpg" alt="Berggipfel in den Alpen">

Bild aus einem Unterordner

Ordner:

index.html
bilder/
    berg.jpg

Dann:

<img src="bilder/berg.jpg" alt="Berggipfel">

Listen

Ungeordnete Liste

Für Stichpunkte:

<ul>
    <li>Steigeisen</li>
    <li>Eispickel</li>
    <li>Seil</li>
</ul>

Geordnete Liste

Für eine Reihenfolge:

<ol>
    <li>Rucksack packen</li>
    <li>Zum Ausgangspunkt fahren</li>
    <li>Aufsteigen</li>
</ol>

Verschachtelte Listen

Listen können ineinander liegen:

<ul>
    <li>
        Hochtour
        <ul>
            <li>Steigeisen</li>
            <li>Eispickel</li>
            <li>Gurt</li>
        </ul>
    </li>

    <li>
        Klettertour
        <ul>
            <li>Klettergurt</li>
            <li>Seil</li>
            <li>Karabiner</li>
        </ul>
    </li>
</ul>

Bereiche & semantische Elemente

div — allgemeiner Container

<div>
    <h2>Meine Tour</h2>
    <p>Informationen zur Tour.</p>
</div>

Ein div kann mehrere Elemente zusammenfassen.

Für eine sauberere Struktur gibt es zusätzlich spezielle, semantische Elemente:

header — Kopfbereich der Seite

<header>
    <h1>Mein Bergprojekt</h1>
    <p>Meine Touren und Erfahrungen</p>
</header>

main — der wichtigste Inhalt der Seite

<main>
    <h2>Willkommen</h2>
    <p>Das ist der Hauptinhalt.</p>
</main>

Auf einer Seite sollte normalerweise nur ein main vorhanden sein.

section — ein thematischer Abschnitt

<section>
    <h2>Meine Touren</h2>

    <p>
        Hier findest du eine Übersicht meiner Touren.
    </p>
</section>

article — eigenständiger Inhalt

<article>
    <h2>Wildspitze</h2>
    <p>Informationen zur Tour.</p>
</article>

Zum Beispiel für einzelne Touren, Blogbeiträge oder Berichte.

footer — Fußbereich

<footer>
    <p>© 2026 Mein Bergprojekt</p>
</footer>

Tabellen

Eine einfache Tabelle:

<table>

    <tr>
        <th>Tour</th>
        <th>Höhe</th>
        <th>Land</th>
    </tr>

    <tr>
        <td>Wildspitze</td>
        <td>3770 m</td>
        <td>Österreich</td>
    </tr>

    <tr>
        <td>Ortler</td>
        <td>3905 m</td>
        <td>Italien</td>
    </tr>

</table>

table = gesamte Tabelle, tr = Tabellenzeile, th = Überschrift einer Spalte, td = normale Tabellenzelle.

Buttons

Ein einfacher Button:

<button>Klick mich</button>

Wichtig: Ein <button> führt allein noch keine Aktion aus. Wenn später JavaScript verwendet wird, kann ein Button Aktionen auslösen.

Links statt Buttons für Navigation

Wenn etwas beim Anklicken nur eine andere Seite öffnen soll, ist grundsätzlich ein Link die richtige Wahl: 

<a href="touren.html">Zu den Touren</a>

Nicht <button>Touren ansehen</button>, wenn der Button eigentlich nur zu einer anderen Seite führen soll.

Attribute, id & class

HTML-Elemente können zusätzliche Informationen bekommen. Beispiel:

<a href="touren.html">Touren</a>

href ist hier ein Attribut. Ein Attribut steht normalerweise innerhalb des öffnenden Tags: 

<tag attribut="wert">

id

Ein Element kann eine eindeutige ID bekommen:

<h2 id="touren">Meine Touren</h2>

Danach kann man direkt zu dieser Stelle springen:

<a href="#touren">Zu den Touren springen</a>

Das # bedeutet: suche das Element mit dieser ID.

class

Mit class kann man Elemente einer Gruppe zuordnen:

<div class="tour">
    <h2>Wildspitze</h2>
</div>

<div class="tour">
    <h2>Ortler</h2>
</div>

class wird später besonders wichtig für CSS.

Kommentare

Kommentare werden vom Browser nicht angezeigt:

<!-- Das ist ein Kommentar -->

Beispiel:

<!-- Navigation -->
<nav>
    ...
</nav>

Kommentare können helfen, den Code zu organisieren.

Vollständiges Beispiel

Eine saubere, einfache Website kann beispielsweise so aufgebaut werden: 

<!DOCTYPE html>
<html lang="de">

<head>
    <meta charset="UTF-8">
    <title>Meine Website</title>
</head>

<body>

    <header>
        <h1>Meine Website</h1>
        <p>Kurze Beschreibung meiner Website.</p>
    </header>

    <nav>
        <a href="index.html">Startseite</a>
        <a href="touren.html">Touren</a>
        <a href="ausruestung.html">Ausrüstung</a>
        <a href="ueber-mich.html">Über mich</a>
    </nav>

    <main>

        <section>
            <h2>Willkommen</h2>
            <p>Hier steht mein Begrüßungstext.</p>
        </section>

        <section>
            <h2>Über diese Website</h2>
            <p>Hier steht eine Beschreibung der Website.</p>
        </section>

        <section>
            <h2>Meine Themen</h2>
            <ul>
                <li>Touren</li>
                <li>Ausrüstung</li>
                <li>Erfahrungen</li>
            </ul>
        </section>

    </main>

    <footer>
        <p>© 2026 Meine Website</p>
    </footer>

</body>
</html>

Grundprinzip eines Tags mit Attribut: 

<tag attribut="wert">Inhalt</tag>

Am Beispiel <a href="touren.html">Touren</a>:

<a>             = HTML-Element
href             = Attribut
"touren.html"    = Wert des Attributs
Touren           = sichtbarer Text
</a>            = Ende des Elements

Mehrseitige Website

Jede eigenständige Seite braucht ihre eigene HTML-Datei. Für eine kleine Website kann die Struktur beispielsweise so aussehen: 

meine-website/
│
├── index.html
│
├── touren.html
├── ausruestung.html
├── ueber-mich.html
│
└── bilder/
    ├── berg.jpg
    ├── tour.jpg
    └── rucksack.jpg

Die index.html ist normalerweise die Startseite. Die Unterseiten werden über <a href="..."> miteinander verbunden — die Startseite verlinkt zur Tourenseite: 

<a href="touren.html">Touren</a>

und die Tourenseite kann wieder zurückverlinken:

<a href="index.html">Zurück zur Startseite</a>

Einrückung & Verschachtelung

Saubere Einrückung

HTML sollte übersichtlich eingerückt werden. Schlecht:

<body><header><h1>Meine Website</h1></header><main><p>Hallo</p></main></body>

Besser:

<body>

    <header>
        <h1>Meine Website</h1>
    </header>

    <main>
        <p>Hallo</p>
    </main>

</body>

Dadurch sieht man sofort, welches Element in welchem anderen Element steckt.

Verschachtelung

HTML-Elemente können ineinander liegen:

<section>

    <h2>Meine Tour</h2>

    <p>
        Das war eine
        <strong>sehr schöne</strong>
        Tour.
    </p>

</section>

Das Prinzip:

section
├── h2
└── p
    └── strong

Tags sollten korrekt geschlossen werden. Richtig:

<p>
    Das ist <strong>wichtiger Text</strong>.
</p>

Falsch:

<p>
    Das ist <strong>wichtiger Text.
</p>
</strong>

Häufige Fehler

Link ohne href

Falsch: <a>Touren</a>

Richtig: <a href="touren.html">Touren</a>

Wenn die Datei touren.html heißt, muss der Link exakt dazu passen. Nicht Touren.html oder tour.html, wenn diese Dateien nicht existieren.

Falscher Ordner

Was ist CSS?

CSS steht für Cascading Style Sheets.

HTML bestimmt hauptsächlich: Was ist auf der Website?
CSS bestimmt: Wie sieht es aus?

Beispiel HTML:

<h1>Meine Website</h1>

Ohne CSS zeigt der Browser die Überschrift einfach mit seinem Standarddesign. Mit CSS kann man zum Beispiel bestimmen:

  • Schriftgröße & Schriftart
  • Farbe
  • Abstand
  • Breite & Höhe
  • Position
  • Hintergrund & Rahmen
  • Ausrichtung

HTML und CSS sind zwei verschiedene Dinge

HTML:

<h1 class="titel">Meine Website</h1>

CSS:

.titel {
    color: blue;
    font-size: 40px;
}

HTML sagt: Das ist eine Überschrift.
CSS sagt: Diese Überschrift soll blau und 40 Pixel groß sein.

CSS einbinden

Eine CSS-Datei sieht beispielsweise so aus: style.css. HTML weiß nicht automatisch, dass diese Datei existiert — man verbindet sie im <head> der HTML-Datei: 

<link rel="stylesheet" href="style.css">

Zum Beispiel:

<head>
    <meta charset="UTF-8">
    <title>Meine Website</title>
    <link rel="stylesheet" href="style.css">
</head>

Bedeutung

<link> stellt eine Verbindung zu einer anderen Datei her. rel="stylesheet" sagt: Diese Datei ist ein Stylesheet. href="style.css" sagt: Die CSS-Datei heißt style.css.

Grundlegende Syntax

Das wichtigste Muster in CSS ist:

selektor {
    eigenschaft: wert;
}

Beispiel:

h1 {
    color: blue;
}

Das bedeutet: Alle h1-Elemente sollen die Eigenschaft color mit dem Wert blue bekommen.

h1 Selektor
color Eigenschaft
blue Wert

Geschweifte Klammern & Semikolon

CSS-Regeln stehen zwischen { und }. Jede Eigenschaft endet normalerweise mit einem ;: 

h1 {
    color: blue;
    font-size: 40px;
}

Ein Element kann beliebig viele Eigenschaften bekommen:

h1 {
    color: blue;
    font-size: 40px;
    font-family: Arial;
}

Kommentare

CSS-Kommentare werden nicht ausgeführt:

/* Überschriften */

h1 {
    color: blue;
}

Elemente, Klassen & IDs

Der Selektor bestimmt: Welches HTML-Element möchte ich verändern?

Elemente direkt auswählen

Man kann HTML-Tags direkt als Selektor verwenden:

h1 {
    color: blue;
}

p {
    color: black;
}

body {
    background-color: white;
}

Damit werden alle entsprechenden Elemente angesprochen.

Klassen

Klassen sind eine der wichtigsten Möglichkeiten, gezielt Elemente anzusprechen.

HTML:

<p class="wichtig">
    Das ist wichtig.
</p>

CSS:

.wichtig {
    color: red;
}

Der Punkt . bedeutet: Ich möchte eine Klasse auswählen. .wichtig spricht class="wichtig" an.

Mehrere Elemente können dieselbe Klasse haben:

<p class="tour">Wildspitze</p>
<p class="tour">Ortler</p>
<p class="tour">Mont Blanc</p>
.tour {
    color: blue;
}

Alle drei bekommen diese Regel — das ist der große Vorteil von Klassen.

IDs

HTML:

<h1 id="haupttitel">
    Meine Website
</h1>

CSS:

#haupttitel {
    color: blue;
}

Das # bedeutet: Wähle die ID aus. #haupttitel spricht id="haupttitel" an.

Klasse oder ID?

Für CSS sollte meistens class verwendet werden. Eine ID ist normalerweise für ein bestimmtes, eindeutiges Element gedacht. 

.klasse   → kann oft mehrfach vorkommen
#id       → soll eindeutig sein

Mehrere & verschachtelte Selektoren

Mehrere Selektoren gleichzeitig

Man kann mehrere Elemente mit derselben Regel ansprechen:

h1, h2, h3 {
    color: blue;
}

Das bedeutet: Wende diese Regel auf h1, h2 und h3 an.

Verschachtelte Elemente auswählen

Man kann auch sagen: Wähle nur p innerhalb von section.

section p {
    color: gray;
}

HTML:

<section>
    <h2>Touren</h2>
    <p>Dieser Text wird grau.</p>
</section>

<p>Dieser Text wird nicht automatisch grau.</p>

Universal-Selektor

* bedeutet: Wähle alle Elemente aus. Sehr häufig:

* {
    box-sizing: border-box;
}

Kaskade & Spezifität

Das „C" in CSS bedeutet Cascading.

Es kann vorkommen, dass mehrere Regeln dasselbe Element beeinflussen:

p {
    color: blue;
}

p {
    color: red;
}

Hier gilt aufgrund der Reihenfolge in diesem einfachen Fall die spätere Regel: color: red;

Wichtige Faktoren dafür, welche Regel gewinnt:

  • !important
  • Spezifität
  • Reihenfolge
  • Vererbung

Für den Anfang reicht: Wenn mehrere gleich starke Regeln dasselbe festlegen, gewinnt normalerweise die spätere.

Spezifität — einfach erklärt

CSS kann unterschiedlich gezielt auswählen:

p {
    color: blue;
}

weniger spezifisch als eine Klasse:

.text {
    color: red;
}

HTML und CSS bauen eine Seite auf. Sie bleibt danach aber so, wie sie ist. JavaScript sorgt dafür, dass auf der Seite etwas passiert.

Normalerweise hat ein Projekt drei Dateien:

Der Browser liest die Datei von oben nach unten. Steht das script ganz unten, ist das HTML darüber bereits geladen — und JavaScript findet die Elemente, die es verändern soll. Steht es oben, sucht JavaScript nach Elementen, die es noch gar nicht gibt.
